# API Contract & Schema Specification: Custom Orders

Shared conventions: `workflows/README.md` §3.5. Guards: `public` / **owner**.

## 1. Global Overview

- **Public submission:** rate limit 5/min/IP (429). **Money:** integer Naira.
- **tx_ref:** `CR-<requestNumber>` (e.g. `CR-000123`), generated by the quote endpoint.

## 2. Endpoints Matrix

| Method | Path | Summary | Auth | Request | Success |
|---|---|---|---|---|---|
| POST | `/api/custom-requests` | Submit bespoke request (FR-030) | public | `CustomRequestInput` | 201 `{ requestNumber, expectedResponseTime }` |
| GET | `/api/admin/custom-requests` | Inbox list | owner | `?status=&q=` | 200 `CustomRequestRow[]` |
| GET | `/api/admin/custom-requests/:id` | Full detail + notes | owner | — | 200 `CustomRequestDetail` |
| PATCH | `/api/admin/custom-requests/:id/status` | Set status (+ note) | owner | `{ status, note? }` | 200 `{ id, status }` |
| POST | `/api/admin/custom-requests/:id/quote` | Create quote + payment link (NT-006) | owner | `QuoteInput` | 200 `QuoteResult` |

## 3. Error Handling & HTTP Status Codes

| Condition | Status | Code | Body |
|---|---|---|---|
| Invalid form fields | 400 | `VALIDATION_ERROR` | zod `details` |
| Rate limited / spam | 429 | `RATE_LIMITED` | `{ error: "Please wait a moment before sending another request." }` |
| Unknown request | 404 | `NOT_FOUND` | `{ error: "Request not found." }` |
| Illegal status move | 409 | `INVALID_TRANSITION` | `{ error: "Declined requests can't be quoted." }` |
| Quote with invalid amount | 422 | `QUOTE_INVALID` | `{ error: "Enter an amount of at least ₦1,000." }` |
| Flutterwave link failure | 502 | `PAYMENT_LINK_FAILED` | `{ error: "We couldn't create the payment link. Try again." }` |
| Staff on owner route | 403 | `AUTH_FORBIDDEN` | `{ error: "Only the owner manages custom requests." }` |

## 4. Type-Safe Schemas & DTO Code Definitions

Zod in `web/src/lib/api/schemas/custom-requests.ts`.

### 4.1 Client Request DTOs

```typescript
export const CustomRequestInput = z.object({
  contact: z.object({
    name: z.string().trim().min(1).max(120),
    email: z.string().trim().email().max(255),
    phone: z.string().trim().regex(/^(\+?234|0)\d{9,10}$/, "Enter a valid Nigerian phone number."),
  }),
  spaceOrSetting: z.string().trim().min(3).max(200),   // "Office in Victoria Island"
  productTypes: z.array(z.enum(["candles", "diffusers", "sprays", "gypsum", "bundle"])).min(1),
  scentPreferences: z.string().trim().min(3).max(1000),
  quantity: z.number().int().min(1).max(5000).default(1),
  budgetRange: z.string().trim().max(60).default(""),  // "₦100k – ₦250k"
  eventDate: z.coerce.date().optional(),
  referenceImage: z.object({
    publicId: z.string().min(1),
    url: z.string().url(),
    alt: z.string().default("Reference image for custom request"),
  }).optional(),
  _hp: z.string().max(0).optional(),                    // honeypot — must stay empty
});
export type CustomRequestInput = z.infer<typeof CustomRequestInput>;

export const StatusUpdateInput = z.object({
  status: z.enum(["new", "quoted", "accepted", "declined", "completed"]),
  note: z.string().max(500).optional(),
});

export const QuoteInput = z.object({
  amount: z.number().int().min(1000),                   // ≥ ₦1,000
  note: z.string().max(1000).optional(),                // shown in the quote email
  deliveryIncluded: z.boolean().default(true),          // is the fee inside the amount?
});
```

### 4.2 Response DTOs

```typescript
export interface CustomRequestRow {                    // inbox list
  id: string; requestNumber: string;
  contact: { name: string; email: string; phone: string };
  spaceOrSetting: string; productTypes: string[];
  quantity: number; budgetRange: string; eventDate?: string;
  status: "new" | "quoted" | "accepted" | "declined" | "completed";
  quoteAmount?: number; hasImage: boolean; createdAt: string;
}

export interface CustomRequestDetail extends CustomRequestRow {
  scentPreferences: string;
  referenceImage?: { url: string; alt: string };
  paymentLink?: { linkUrl: string; txRef: string; amount: number;
    status: "pending" | "successful" | "failed" };
  orderId?: string; orderNumber?: string;              // once paid
  quotedAt?: string;
  notes: { userName: string; note: string; at: string }[];
  expectedResponseTime: "48 hours";
}

export interface QuoteResult {
  requestNumber: string; quoteAmount: number;
  paymentLinkUrl: string;                                // emailed to customer (NT-006)
  deliveryIncluded: boolean;
}
```

## 5. OpenAPI 3.0 Specification (custom orders slice)

```yaml
openapi: 3.0.3
info: { title: Ligera Custom Orders API, version: 1.0.0 }
servers: [{ url: https://app.ligera.ng }, { url: http://localhost:3000 }]
paths:
  /api/custom-requests:
    post:
      summary: Submit a bespoke request (FR-030)
      requestBody:
        required: true
        content:
          application/json:
            schema:
              type: object
              required: [contact, spaceOrSetting, productTypes, scentPreferences]
              properties:
                contact:
                  type: object
                  required: [name, email, phone]
                  properties:
                    name: { type: string }
                    email: { type: string, format: email }
                    phone: { type: string }
                spaceOrSetting: { type: string }
                productTypes:
                  type: array
                  items: { type: string, enum: [candles, diffusers, sprays, gypsum, bundle] }
                scentPreferences: { type: string }
                quantity: { type: integer, default: 1 }
                budgetRange: { type: string }
                eventDate: { type: string, format: date }
                referenceImage: { type: object }
      responses:
        "201":
          description: Request received
          content:
            application/json:
              schema:
                type: object
                properties:
                  requestNumber: { type: string, example: CR-000123 }
                  expectedResponseTime: { type: string, example: "48 hours" }
        "400": { $ref: "#/components/responses/Error" }
        "429": { $ref: "#/components/responses/Error" }
  /api/admin/custom-requests:
    get:
      summary: Owner inbox (AD-046)
      security: [{ cookieAuth: [] }]
      parameters:
        - in: query
          name: status
          schema: { type: string, enum: [new, quoted, accepted, declined, completed] }
        - { in: query, name: q, schema: { type: string } }
      responses:
        "200":
          description: Requests
          content:
            application/json:
              schema:
                type: array
                items: { $ref: "#/components/schemas/CustomRequestRow" }
        "403": { $ref: "#/components/responses/Error" }
  /api/admin/custom-requests/{id}/status:
    patch:
      summary: Set status with optional note
      security: [{ cookieAuth: [] }]
      parameters: [{ in: path, name: id, required: true, schema: { type: string } }]
      requestBody:
        required: true
        content:
          application/json:
            schema:
              type: object
              required: [status]
              properties:
                status: { type: string, enum: [new, quoted, accepted, declined, completed] }
                note: { type: string }
      responses:
        "200": { description: Updated }
        "409": { $ref: "#/components/responses/Error" }
  /api/admin/custom-requests/{id}/quote:
    post:
      summary: Quote amount and create payment link (NT-006)
      security: [{ cookieAuth: [] }]
      parameters: [{ in: path, name: id, required: true, schema: { type: string } }]
      requestBody:
        required: true
        content:
          application/json:
            schema:
              type: object
              required: [amount]
              properties:
                amount: { type: integer, minimum: 1000, description: Naira }
                note: { type: string }
                deliveryIncluded: { type: boolean, default: true }
      responses:
        "200":
          description: Quote created
          content:
            application/json:
              schema:
                type: object
                properties:
                  requestNumber: { type: string }
                  quoteAmount: { type: integer }
                  paymentLinkUrl: { type: string }
        "422": { $ref: "#/components/responses/Error" }
        "502": { $ref: "#/components/responses/Error" }
components:
  securitySchemes: { cookieAuth: { type: apiKey, in: cookie, name: ligera_at } }
  responses:
    Error:
      description: Error envelope
      content:
        application/json:
          schema:
            type: object
            properties: { error: { type: string }, code: { type: string } }
  schemas:
    CustomRequestRow:
      type: object
      properties:
        id: { type: string }
        requestNumber: { type: string }
        status: { type: string, enum: [new, quoted, accepted, declined, completed] }
        quoteAmount: { type: integer }
        createdAt: { type: string, format: date-time }
```
